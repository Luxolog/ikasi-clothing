# IKASI Clothing — storefront prototype

A responsive static storefront for GitHub Pages, using the product images supplied for the first IKASI collection.

## Products loaded
- Fear Not T-shirt — R400 (white, black)
- Hustle Hard Hoodie — R600 (white, black)
- Lion of Judah Sweater — R500 (grey, red, navy, black)
- Branded IKASI Cap — R250 (blue, red, black)

Clothing products include size selectors; colour changes update the product image. The shopping bag is a front-end demo and persists in the current browser.

## Publish on GitHub Pages
1. Upload the contents of this folder to the root of `Luxolog/ikasi-clothing`.
2. Commit the changes to `main`.
3. Open **Settings → Pages** and select **Deploy from a branch**, branch `main`, folder `/ (root)`, then Save.
4. Wait for the Pages deployment to finish under **Actions**.

## Important before launch
Checkout, payment processing, shipping, inventory, and newsletter subscription are not connected. Do not accept live orders until a secure order/payment workflow has been configured and tested.
